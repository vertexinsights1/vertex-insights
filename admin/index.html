Security checklist

  • Never put a service-role key in admin/config.js or any browser code.
  • Disable public sign-ups in Supabase Auth.
  • Create the first owner profile manually using the setup guide.
  • Use a strong unique password and secure account email.
  • Configure and test email notifications before launch.
  • Test database RLS with a non-admin session before public launch.
